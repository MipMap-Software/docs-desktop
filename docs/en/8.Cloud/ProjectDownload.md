## Download to Local


> [!tip] For projects uploaded to cloud storage, click Download to Local. Select your desired output formats via Output Export.

On the main interface, click ![image-20260527152745176](/img/cn-img/image-20260527152745176.png) at the top-left corner of the project card. On the output interface, click ![image-20260527152748254](/img/cn-img/image-20260527152748254.png) at the top-right corner to open the project download panel.

<div style="display:flex; gap:12px;justify-content:center;">

<img src="/img/en-img/download.png" style="width:50%;">

<img src="/img/en-img/download2.png" style="width:50%;">

</div>



Select the tasks you want to download to pull cloud-hosted tasks onto local storage. If the task already exists locally, the download will overwrite local data.
