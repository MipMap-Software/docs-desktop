## Upload to Cloud

::: tip Reconstructed projects can be uploaded to cloud storage for output sharing or in-cloud preview.
:::

On the main interface, click ![](/img/cn-img/image43.png) at the top-left corner of the project card. On the output interface, click ![](/img/cn-img/image43.png) at the top-right corner to open the project upload panel.

For already-uploaded tasks, click ![image-20260527153236793](/img/cn-img/image-20260527153236793.png) to overwrite and update the uploaded task.

<img src="/img/en-img/upload2.png" style="width:50%;">

</div>



The progress bar below shows the memory consumed by the upload and the available cloud storage capacity.
>[!warning] Upload will fail if the required size exceeds available cloud storage. Purchase additional cloud storage or clean up existing cloud-stored data.
