## Software Operation

---

### Antivirus Software Blocks Installation

Cause: The software lacks a digital signature. The installer downloaded from official channels contains no viruses.

:::tip Solutions
Exit the antivirus software before reinstalling. Add the software installation directory to the antivirus trust list. Restore quarantined files if they have been isolated.
:::

---

### Network or Server Status error

![](/img/en-img/networkerror.png)

:::tip Solutions

Check whether the network connection is normal.
