### Cloud Synchronization Status Description

There are three statuses as follows

![](/img/cn-img/image43.png): The project exists only locally. Click the icon to upload it to cloud storage.

![](/img/cn-img/image44.png): The project exists both locally and in cloud storage. Click the icon to re-upload or download.

![](/img/cn-img/image45.png): The project exists only in cloud storage. Click the icon to download it to local disk.
