### License Version

![](/img/en-img/edition.png) Displays the currently bound license version. If the displayed version does not match your purchased version, please check License Management.

![](/img/en-img/diskspace.png) When the free disk space of the drive where the working directory is located is less than 100 GB, a pop‑up will display the remaining available disk space.

![](/img/en-img/license.png) 
When fewer than fifteen days remain before license expiration, the remaining validity days will be shown.

> [!warning] Please pay attention to the remaining disk space and remaining valid days to prevent project reconstruction failure caused by insufficient disk space or license expiration.

Differences between versions:
- Free Edition: Maximum 500 images per task; laser point cloud reconstruction is not supported.
- Basic Edition: Maximum 5000 images per task; laser point cloud reconstruction is not supported.
- Professional Edition: Unlimited number of processed images; laser point cloud reconstruction is not supported.
- Ultra Edition: Unlimited number of processed images; laser point cloud reconstruction is supported.

### Settings

Click ![](/img/en-img/settingslogo.png) to open the user-settings panel.

#### Preferences

- Language: Click the drop‑down box to select and switch languages.
- Working Directory: Click the edit icon to select the project storage path. Check Migrate existing project files to move all current project files to the specified path.
- Basemap Service: Switch the base map. Internet connection is required for map loading and display.
- Length Unit: Switch the length unit. Units for annotations and measurements will update accordingly.
- Area Unit: Switch the area unit. Units for annotations and measurements will update accordingly.
- Volume Unit: Switch the volume unit. Units for annotations and measurements will update accordingly.
- Auto Merge Cameras: Options: Allow / Ask / Deny. Automatically merge photos from the same camera upon import. When set to Ask, auto-merge takes place only if device serial number, photo resolution and focal length are identical.
- User Experience Improvement Plan: When enabled, your device information and essential diagnostic and log data will be sent to MipMap to help improve product quality and user experience.

![](/img/en-img/settings2.png)

#### License

Click License to view Software Version, License Status, License Type and Expiration Date.
> [!CAUTION] License bound to account: multi‑device login allowed, but only one active session at a time. Concurrent use triggers prompt to kick other licenses.

![](/img/en-img/license2.png)

![](/img/en-img/licensetip.png)
