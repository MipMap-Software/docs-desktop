## Project Related

![](/img/en-img/project.png)

---

### Project Search

![](/img/en-img/list1.png) Enter the full project name or keywords to search for projects.

---

### Project Filter

![](/img/en-img/filter.png) Click the filter drop-down box to select filter conditions.

- Local Project: Display projects stored locally.
- Cloud Project: Display projects uploaded to cloud storage.
- Tag: Display projects containing the selected tags.
- Reset: Reset all selected filter conditions.

![](/img/en-img/filter2.png)

---

### Project Sorting

- By Name: Sort all projects on the main interface alphabetically from A to Z.
- By Creation Time: Sort all projects on the main interface from newest to oldest by creation time.
- By Update Time: Sort all projects on the main interface from newest to oldest by update time.

---

### Project Display

Card View ![](/img/en-img/cardmode.png): Display projects on the main interface in card view.

List View ![](/img/en-img/listmode.png): Display projects on the main interface in list view.

**Project Status**: ![](/img/en-img/image32.png)![](/img/en-img/image33.png)![](/img/en-img/image34.png)![](/img/en-img/image35.png)

Waiting, Running, Stopped, Error.

**Project Outputs**: ![](/img/en-img/image36.png)![](/img/en-img/image37.png)

AT (Aerial Triangulation only), 2D (2D outputs available), 3D (3D outputs available), GS (Gaussian Splatting outputs available).

---

### Multi-select for Projects

- Single Selection: Click a project card to select a project.
- Select All: Select all projects.
- Clear All: Clear current selections.
- Export Project: Export selected projects to the specified folder in `mprj` format.
- Delete Project: Delete the selected projects.

![](/img/en-img/select.png)

---

### Import Project

![](/img/en-img/image39.png) Select an `mprj` project file to import it into the project list.

---

### Refresh Projects

![](/img/en-img/image40.png) Refresh the status of all projects on the main interface.

---

### New Project

![](/img/en-img/newproject.png) Enter the project name and select the corresponding initial task type based on data type.

![](/img/en-img/newproject2.png)

---

### Project Options

- Copy: Copy parameters and aerial triangulation outputs of the current project.
- Export: Export the current project to the specified folder in `mprj` format.
- Rename: Modify the name of the current project.
- Tag Management: Add or remove tags for the current project.
- Upload to Cloud: Select tasks within the current project for upload to cloud storage.
- Download to Local: Download the cloud-stored project to local disk.
- Delete: Delete the current project.

![](/img/en-img/opt.png)
