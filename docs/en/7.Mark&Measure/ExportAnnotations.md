## Export Annotations



![](/img/en-img/exportannotation.png)

::: tip Operation Steps

1. Click ![](/img/en-img/image118.png) to export all annotations of the current task.

2. Select the required data format.

3. Choose the export coordinate system / elevation datum.

4. Data is saved as a ZIP archive by default. Simply select the target save directory.
:::
