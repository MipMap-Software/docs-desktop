## Time-Series Task Management

Time-Series Task Management is built on a project-multi-phase task architecture. It is mainly designed for datasets of the same survey area captured at different time periods, enabling quick access to multi-phase outputs and time-series comparative analysis.

![](/img/en-img/task.png)

---

### Usage Instructions

- Click New Project, enter the project name, import the first-phase data and complete reconstruction.
- For each subsequently-captured dataset, open the existing project, create a new task and run reconstruction to import multi-phase data.
- The project loads outputs of the latest phase by default, so you can reference current-period conditions and review historical data from previous phases.
- Thumbnail cards for all time-series tasks are arranged horizontally on the top navigation bar, each tagged with its acquisition date.
- Click any card to switch to the output view of the corresponding time period. One-click switching is available without repeated data import or project file switching.

---

### Application Domains

- Natural Resources: land verification, mine exploitation monitoring, dynamic cultivated-land monitoring.
- Infrastructure Projects: construction-progress comparison for roads, bridges, water conservancy and building sites.
- Urban-Rural Development: old-town renewal, urban expansion, urban-planning verification.
- Agriculture, Forestry & Environmental Protection: afforestation and revegetation, high-standard farmland, river-lake ecological monitoring.
- Disaster Prevention & Safety Supervision: landslide hazard monitoring, post-flood disaster-impact comparison.
