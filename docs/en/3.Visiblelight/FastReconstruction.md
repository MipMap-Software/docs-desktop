## Quick Reconstruction

---

### 1. Create New Project

Click New Project ![](/img/en-img/newproject.png), enter the project name, and select **Visible Light** as the task type.

![](/img/en-img/newproject2.png)

---

### 2. Import Data

![](/img/en-img/imgimport.png)

For photo files, click Import Folder and select the photo folder for import.

For video files, click Import Video. The default 1-second frame-extraction interval is sufficient.

---

### 3. Select Products

Select a reconstruction template; or manually enable required 2D products, 3D products formats, and products coordinate system.

![](/img/en-img/products.png)

---

### 4. Start Reconstruction

Click Start Reconstruction ![](/img/en-img/star.png)
