## Pre-usage Preparation

Before using the software, you need to activate it and complete essential preference settings.

---

### Software Activation

1. Log in to MipMap Desktop and click **Try Ultra for 15 Days** to claim a 15-day trial license for the Ultra edition.
 
![](/img/en-img/15daytrial2.png)

2. The license icon changes from Free to Ultra Edition, which indicates the claim is successful.

![](/img/en-img/15daytrial.png)

---

### Set Working Directory

`C:\Users\Administrator\Documents\mipmap-desktop` is the default working directory of the software. It stores intermediate files and final model outputs generated during project modeling, which may consume substantial disk space.

> [!tip] It is recommended to assign the working directory to a disk with ample free space. An SSD delivers optimal performance.

![](/img/en-img/workingdirectory.png)

Before modifying the working directory, choose whether to migrate existing project files. If checked, files from the current working directory will be moved to the new path. A long waiting time may occur for large-sized files.

![](/img/en-img/workingdirectory2.png)

---

### PC Configuration Check

For better performance, set your power mode to **Best Performance**, and configure all screen and sleep-related power settings to **Never**.

![](/img/en-img/power.png)
